# 踩坑记录（症状 → 原因 → 修复）

## 1. 多盘工程打开后只有 1 号盘有零件

**症状**：3MF 里有 3 个 `<plate>`，盘名/缩略图都在，但 2、3 号盘是空的；所有零件
都堆在 1 号盘（或被移到 1 号盘）。

**原因**：把每个盘的零件都排在局部床中心 `(128,128)`。Bambu 用**全局坐标**
判断盘归属：盘间距 `stride = 床宽 × 1.2`，第二行盘在负 Y。

**修复**：按盘序号平移零件（见 `3mf-format.md` 的 `origin(p)`）。验证方法：
用 Bambu CLI `--export-3mf` 重导出，数每个盘的 `model_instance` 数量。

**教训**：单盘工程永远看不出这个问题——所有零件本来就该在盘 1。

## 2. 两个零件在 Bambu 里变成一个 / 少件

**原因**：`3D/Objects/object_i.model` 内部 object id 或 `part id` 重复（常见是
全部写成 1）。

**修复**：第 i 个零件用 `2i-1` 作为内部/part id，`2i` 作为包装对象 id，并让
`component objectid` 指向 `2i-1`。

## 3. 盘缩略图空白

**原因**：缺 `plate_N.png` / `plate_no_light_N.png` / `top_N.png` / `pick_N.png` /
`plate_N_small.png`，或 `model_settings.config` 里路径大小写/编号不匹配。

**修复**：每盘补齐 5 张；渲染时把所有零件 `hide_render=False`（`copy()` 会继承
旧对象的隐藏状态）。

## 4. macOS 上能跑，换平台就挂

**原因**：用了 `sips -z 128 128`（仅 macOS）或写死 `/Applications/...`。

**修复**：缩略图用 Blender 图像 API 缩放；Blender 可执行文件由用户通过
`$BLENDER` 或 PATH 提供；临时目录用 `tempfile`。

## 5. 模板放在 /tmp 里，过几天导出失败

**原因**：`/tmp` 会被清理；模板路径写死。

**修复**：模板入库（`bricks/bambu_template/`），脚本用仓库相对路径并支持
`BAMBU_TEMPLATE` 覆盖。

## 6. 验证脚本误报"碰撞"

**症状**：两个零件正好贴合（如斜面底面落在砖顶 9.6 mm），干涉体积几百 mm³，
但检查交集体包围盒发现**高度为 0**。

**原因**：共面接触时 EXACT 布尔会生成零厚度薄片。

**修复**：过滤交集网格的 Z 高度 `< 0.05 mm` 的结果，视为贴合而非重叠。
（`bricks/verify_assembly.py` 已实现。）

## 7. 薄环干涉体积乱跳（0.05 mm 级）

**症状**：tile 的 4 个 ∅4.4 腔与 ∅4.5 凸点，理论干涉 ~5 mm³，实测 78 mm³ 或 0。

**原因**：薄壁环超出布尔数值精度，结果网格自相交。

**修复**：不要用体积判定这种配合；改用探针（小立方体求交是否为空）或直接量
腔壁半径。

## 8. 布尔之后所有面变黑 / 材质丢失

**原因**：布尔/合并插入了 `None` 材质槽（index 0）。

**修复**：清空材质槽、追加一个材质、把所有 `polygon.material_index` 设为 0。

## 9. 倒角顺序错误导致装配口变小

**症状**：腔口从 4.8 变成 4.5，凸点边缘刮擦。

**原因**：先切腔、后倒角，倒角把腔口也收进去了。

**修复**：先在原始方体上倒角（仅外棱，`limit_method="ANGLE"`），再切腔；
腔口保持锐边。

## 10. 支撑/碰撞只检查了包围盒

**症状**：模型看起来没重叠，实际凸点插进了别的砖。

**修复**：做真实布尔求交（EXACT），并区分"贴合"（零厚度）与"重叠"（有体积）。

## 11. 打印件配合和设计值不一致

**症状**：设计 0.05 mm 过盈，实际要老虎钳；或设计 0.15 间隙，实际很松。

**原因**：FDM 小圆孔会缩 0.05~0.15 mm，方腔收缩较小；不同材料/温度也有差异。

**修复**：以实打反馈为准，按 0.05 mm 步进调整；圆孔比方腔多留 0.05~0.1 mm。
详见 `blender-bricks-kit` 的 `references/clutch-tuning.md`。
