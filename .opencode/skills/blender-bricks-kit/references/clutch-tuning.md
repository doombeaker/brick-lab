# 配合（clutch）调整记录与经验

所有数据来自同一位打印者（Bambu Lab P2S、PLA、0.20 mm、textured PEI）的真实
试打反馈。**改配合前先读这里，避免重复已经踩过的坑。**

## 结论表

| 类型 | 当前值 | 类型 | 手感 |
|---|---|---|---|
| `brick_1x1` | 方腔 4.40 | 过盈 0.05/边 | 卡紧，甩不掉 |
| `brick_1x2` | 方腔 4.45 | 过盈 0.025/边 | 轻推入位 |
| `round_brick_1x1` | 圆孔 4.65 | 名义零配合 | 轻按到位（FDM 收缩提供实际握力）|
| `slope_2x2_45` | 管孔 4.60 | 间隙 0.05/边 | 小孩可手推 |
| `tile_2x2` | 盲腔 4.60 | 间隙 0.05/边 | 轻按到位（浅腔实际比 slope 更轻）|
| 标准 2xN 砖 | 管孔 4.80 | 间隙 0.15/边 | 已验证基准 |
| 所有板 | 管孔 4.80 | 间隙 0.15/边 | 已验证基准（2x4） |
| `plate_1x2` | 方腔 4.80 | 间隙 0.15/边 | 单排无管，与板一致 |

## 历史（按时间顺序）

1. **1x1 方砖**：4.80 松 → 4.65（0.075/边）仍松 → **4.40** 卡紧 ✓
   原因：单钉、无管，只有 4 个腔壁接触，摩擦不足。
2. **圆 1x1**：4.70 太松 → 4.40 卡紧 → 4.45 **仍很紧** → **4.65** 名义零配合 ✓。
   教训：此打印机的 4~5mm 圆孔收缩 > 0.1mm，比经验区间（0.05~0.15）的中值还大；
   方腔零补偿即顺手（1x2 经验），**圆孔必须净放 0.1~0.2 收缩补偿**再谈过盈量。
   0.05 步进在圆孔上追不上收缩，连续两轮试打才定位——以后圆孔从名义零配合起步。
3. **斜面**：4.80 完全没握力（斜切让接触面变少）→ 加离合管并做 4.40 过盈；
   实测**要老虎钳** → 4.46 仍紧 → **4.60 间隙**，小孩可推入 ✓
4. **tile**：4.40 偏紧、塞不到底 → 4.46 仍紧（浅盲腔 ×4 同过盈，加上圆孔收缩）→
   **4.60 间隙**（参照已验证的 slope 同值管孔；浅腔 1.9mm 握力弱，间隙档反而合适）✓
   经验：盲腔类（浅接触）与全长管类手感不同档——管用间隙 0.15，盲腔用 0.05 即可。
5. **plate_1x2**：1 格宽放不下离合管（管 OD 6.4 > 内腔 5.2），最初漏了收紧
   腔体（5.2 会晃）→ 改成 4.80 标准间隙（与板一致）

## 经验规则

- **FDM 小圆孔会缩**：直径 4~5 mm 的孔实际可能小 0.05~0.15 mm；方腔收缩小。
  同样"名义过盈 0.05"，圆形会比方形紧得多。
- **接触面积决定手感**：斜面只有 2 个短管、tile 有 4 个深腔，相同过盈量下
  阻力不同。
- **按 0.05 mm 步进调**，一次只改一个变量，并单件试打；不要一次改多个砖型。
- **判断方向**：
  - 需要工具才能压入 → 放 0.05~0.1
  - 松到一翻就掉 → 收 0.03~0.05（圆形优先收）
  - 刚好"轻按到位、拿起不掉"即目标
- **验证脚本的边界**：0.02~0.05 mm 级干涉的布尔体积不可靠（噪声大），用
  几何测量（腔半宽）或探针法；共面贴合会被误判为碰撞，用交集体高度过滤。

## 修改步骤

1. 只改 `bricks/build_bricks.py` 里对应单元的参数（`cavity_tighten` 或
   斜面管孔半径）。
2. 同步 `bricks/bricks.json` 的 `clutch.size_mm`。
3. 重跑 build → verify → check_specs → export。
4. 重新生成示例项目（`examples/*/make_all.py`）并跑 `tools/check_consistency.py`。
5. 试打单个零件，确认后再批量打印。
